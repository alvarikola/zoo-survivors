# Zoo Survivors (web)

Requisitos: Node 18+.

    npm install
    npm run dev      # ver la web en http://localhost:4321
    npm run build    # genera la carpeta dist/ lista para subir

- Enlace de descarga y correo: `src/data/site.js`
- Añadir un animal: `src/data/animales.js` (copia un bloque)
- Las páginas Armas, Enemigos y Novedades son esqueletos en `src/pages/`
- Sprites: carpeta `public/sprites/`. Para el gato, guarda `gato.png` ahí y pon `sprite: '/sprites/gato.png'` en `src/data/animales.js`
